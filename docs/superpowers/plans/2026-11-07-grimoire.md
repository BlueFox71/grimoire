# Grimoire Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Appli Flutter (Android + Windows) qui affiche la PAL Booknode de Jules avec des filtres thèmes/tropes, des statuts et notes, l'ajout via Google Books, et une synchro PC ↔ téléphone par QR code.

**Architecture:** Logique pure en Dart sous `app/lib/core/` (modèle, filtres, import, fusion), testée sans UI ; persistance dans un fichier JSON unique ; UI Flutter sous `app/lib/ui/` avec `provider`. L'export Booknode est un script JavaScript séparé (`tools/booknode-export/`) que Claude exécute dans le Chrome de Jules et qui produit `booknode-export.json` ; l'appli ne contacte jamais Booknode.

**Tech Stack:** Flutter 3.47 / Dart 3.13 (`C:\dev\flutter\bin`), provider, path_provider, http, cached_network_image, mobile_scanner, qr_flutter, file_selector, google_fonts, shared_preferences ; Node (tests du script d'export) avec linkedom.

**Spec:** `docs/superpowers/specs/2026-11-07-grimoire-design.md`

## Global Constraints

- Textes de l'UI en français.
- L'appli ne fait **aucune** requête vers `booknode.com` (seules les images `cdn1.booknode.com` sont téléchargées comme images ; échec → aplat de couleur + titre).
- Le script d'export : jamais de faux en-têtes, lectures de même origine dans l'onglet de Jules, ≥ 1 s entre deux requêtes.
- Thème/trope retenu si `up >= 3 && up >= 2 * down`.
- Liste → statut/note : `pal`→à lire ; `en_cours`→en cours ; `diamant`★5, `or`★4, `argent`★3, `bronze`★2, `pas_apprecie`★1 → lu ; `lu_aussi`→lu sans note (0).
- Livre « à compléter » si moins de 3 étiquettes affichées (thèmes + tropes retenus, retouches manuelles comprises).
- Couleurs sombre « Grimoire nocturne » : fond `#1b1626`, surface `#2e2640`, texte `#ece6f7`, secondaire `#a99cc4`, accent `#8a5cf6`, titre/or `#e8c77a`. Clair « Aube rosée » : fond `#fbf4f6`, surface `#f0e1e8`, texte `#3b2733`, secondaire `#8a6d7c`, accent et titres `#a8456f`. Titres Cormorant Garamond, texte Nunito Sans.
- Thème par défaut = système ; réglage forçable clair/sombre.
- Synchro : serveur PC 2 min, clé aléatoire 32 octets base64url à usage unique, en-tête `X-Grimoire-Key`, requête sans bonne clé → 403.
- Messages de commit terminés par les deux lignes d'attribution de la session.

## Review Focus

1. **Export partiel (`complete: false`) ou `details: null`** : l'import ne doit retirer aucun livre ni vider résumé/thèmes existants. → tests dans Task 4.
2. **Même livre modifié sur PC et téléphone entre deux synchros** (note sur l'un, commentaire sur l'autre) : les deux modifications survivent. → test dans Task 5.
3. **Livre retiré sur un appareil puis modifié sur l'autre** : la pierre tombale la plus récente ou la modification la plus récente gagne, sans résurrection silencieuse. → test dans Task 5.
4. **Titres avec accents/majuscules différents** (Google Books « Le prince cruel » vs Booknode « Le Prince Cruel ») : reconnus comme le même livre à l'import. → test dans Task 4.
5. **Fichier de bibliothèque corrompu ou écriture interrompue** : l'appli ne perd pas la base (écriture atomique + sauvegarde) et démarre avec la dernière sauvegarde valide. → test dans Task 3.

### Task 4: Import d'un export Booknode

**Files:**
- Create: `app/lib/core/booknode_import.dart`

**Interfaces:**

- Produces:
  - `class ImportReport { List<String> added, updated, removed, differs; }` (titres).
  - `ImportReport applyExport(Library lib, Map<String, dynamic> export, DateTime now)` — lève `FormatException` si `format != 'grimoire-booknode-export'` ou `version != 1`.
  - Règles (spec §3), dans cet ordre pour chaque livre de l'export :
    1. Trouver le livre : `bn:<booknodeId>` ; sinon un livre sans `booknodeId` avec `normalize(title)` et `normalize(authors.first)` égaux → lui attacher l'id (le ré-indexer sous `bn:<id>`) ; sinon créer (statut/note selon `list`, `addedAt` de l'export) → `added`. Un livre trouvé mais `deleted` → ignoré.
    2. Si `details != null` : met à jour titre, auteurs, type, série, tome, résumé, couverture, `tags` (thèmes `TagKind.theme`, tropes `TagKind.trope`) ; si `details == null` : seuls titre/auteurs/type mis à jour ; ne jamais vider un champ existant avec une valeur absente.
    3. Si `list != lastBooknodeList` (et livre non créé à l'instant) : si `userEditedAt['status']` ou `userEditedAt['rating']` est postérieur à `lib.lastImportAt` → ne rien changer, ajouter à `differs` ; sinon appliquer statut/note → `updated`.
    4. `lastBooknodeList = list` ; tout champ modifié met `updatedAt[groupe] = now` (pas `userEditedAt`).
  - Si `export['complete'] == true` : chaque livre visible avec `booknodeId` absent de l'export est mis `deleted = true` (`updatedAt['deleted'] = now`) → `removed`, **sauf** s'il est `reading`, ou `read` avec `userEditedAt['rating']` ou `userEditedAt['comment']` défini.
  - Enfin `lib.lastImportAt = now`.
